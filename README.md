# Kisan Mitra AI

An AI-powered agriculture assistant built using Python Flask and Google Gemini API.

## Features
- Crop recommendations
- Disease diagnosis support
- Hindi and English chatbot
- Fertilizer suggestions
- Irrigation guidance

## Technologies Used
- Python
- Flask
- Google Gemini API
- HTML/CSS/JavaScript

## How to Run

pip install -r requirements.txt

python app.py
